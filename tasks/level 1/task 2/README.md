# Cognifyz Data Analysis Internship

## Level 1 — Task 2: City Analysis

### Objective

Analyze restaurant distribution and ratings across cities using the restaurant dataset.

### Tasks

1. Identify the city with the highest number of restaurants.
2. Calculate the average rating of restaurants in each city.
3. Determine the city with the highest average rating.

### Technologies Used

* Python
* Pandas
* Matplotlib

### Analysis Process

1. Load the restaurant dataset.
2. Validate the required columns.
3. Clean city names and convert ratings to numeric values.
4. Count restaurants in each city.
5. Calculate average ratings for each city.
6. Identify the cities with the highest restaurant count and average rating.
7. Export the results to CSV files.
8. Generate charts to visualize the findings.

### Output Files

* `outputs/city_restaurant_counts.csv`
* `outputs/city_average_ratings.csv`
* `outputs/city_analysis_summary.csv`
* `outputs/top_cities_by_restaurants.png`
* `outputs/top_cities_by_rating.png`

### Rating Calculation

Average City Rating = Sum of valid restaurant ratings in a city / Number of restaurants with valid ratings in that city.

Restaurants with missing ratings are excluded from the average rating calculation.
