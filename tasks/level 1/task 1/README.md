# Cognifyz Data Analysis Internship

## Level 1 — Task 1: Top Cuisines

### Objective

Identify the three most common cuisines in the restaurant dataset and calculate the percentage of restaurants serving each cuisine.

### Technologies

* Python
* Pandas
* Matplotlib

### Methodology

1. Load the restaurant dataset.
2. Check the required Cuisines column.
3. Handle missing cuisine values.
4. Split multiple cuisines into individual entries.
5. Count the occurrences of each cuisine.
6. Identify the top three cuisines.
7. Calculate their percentages.
8. Export the results to CSV.
9. Create a bar chart.

### Results

| Rank | Cuisine      | Restaurant Count | Percentage |
| ---- | ------------ | ---------------: | ---------: |
| 1    | North Indian |            3,960 |     41.46% |
| 2    | Chinese      |            2,735 |     28.64% |
| 3    | Fast Food    |            1,986 |     20.79% |

### Key Findings

* North Indian is the most common cuisine.
* Chinese is the second most common cuisine.
* Fast Food is the third most common cuisine.

### Output Files

* `outputs/top_3_cuisines.csv`
* `outputs/top_3_cuisines.png`

### Formula

Percentage of restaurants = (Restaurants listing a cuisine / Total restaurant records) × 100

A restaurant can serve multiple cuisines, so the percentages may overlap.
